# Changelog

All notable changes to JAYCEE Lottery are documented here.

## 2.0.0 - 2026-08-30

### Added

- Native C++20 Windows application with a custom per-user installer.
- Modern Direct2D operator dashboard and separate audience display.
- Numeric coupon and named-participant draw modes.
- UTF-8 participant CSV import with prize eligibility groups.
- Multiple prizes, per-prize winner counts, and group restrictions.
- Candidate confirmation and redraw workflow.
- Optional no-repeat pool and persistent confirmed history.
- Winner report export to UTF-8 CSV.
- Audience welcome slides, countdown, reveal sound, and confetti.
- Interface scaling from 75% to 135% and mouse-wheel page scrolling.
- JAYCEE black-and-white J icon across the app, installer, taskbar, and shortcuts.

### Changed

- Product name updated to JAYCEE Lottery.
- Event titles are optional and the former default celebration title is removed.
